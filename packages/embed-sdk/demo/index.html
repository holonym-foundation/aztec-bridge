Shield embed harness

Serve this file from a different origin than the app (e.g. npx serve -l 8080 packages/embed-sdk/demo against the app on :3000). Same-origin framing would not exercise storage partitioning, third-party cookie policy, or the CSP allowlist.

Add this harness origin to EMBED_ALLOWED_ORIGINS in frontend/.env.local, restart the dev server, and the frame renders. Remove it and the frame must go blank with a CSP violation in the console — that is the allowlist working.
